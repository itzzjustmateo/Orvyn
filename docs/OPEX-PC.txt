Opex PC access
==============

Choose a project folder on the USB in Opex and click Connect project.
Chat and Plan do not execute actions. Agent proposes a file read, file change,
or PowerShell command. Review and approve each step, then click Propose next
step to continue.

File actions check that paths remain within the selected folder. Changes show
a diff, check that the content has not changed, and save the original with path
information under backups/opex-*. New files require an existing parent folder.

PowerShell runs with the current Windows user's permissions. It is not a
sandbox: commands can access locations outside the project and use the internet.
The process tree is stopped after 60 seconds. Output is stored under logs/opex.
When using an API model, shared content and output are sent to that provider.
The action session is temporary and ends when the workspace closes.

Chat mode (Chat, Plan, Code) is saved with your preferences. The logo is embedded
in the Windows application and used by the main window. Close Orvyn and run
START.bat to load an updated executable. Linux support is not included.
